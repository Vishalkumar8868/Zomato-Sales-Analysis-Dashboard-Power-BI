# Zomato-Sales-Analysis-Dashboard-Power-BI
"Interactive Power BI dashboard analyzing 9,545+ restaurants across 141 cities — ratings, votes, and cuisine-wise performance with dynamic filters."

# Key Insights
1. Analyzed 9,545+ restaurants across 141 cities in 15 countries
2. Total votes received: 4M+
3. Majority of restaurants rated "Average" (39.13%), followed by "Good" and "Not Rated"
4. North Indian cuisine leads with 31.33% share, followed by Chinese (19.14%) and Fast Food
5. New Delhi dominates restaurant distribution with 57.33% share among top cities
6. Restaurants analyzed across multiple price ranges and delivery options

# Features
1. Dynamic Filters — filter by delivery status, online delivery availability, price range, and country
2. KPI Cards — real-time metrics for total restaurants, countries, cities, votes, and average cost
3. Ratings Breakdown — votes distribution by rating category (Excellent, Very Good, Good, Average, Poor)
4. Cuisine-wise Analysis — treemap visualization showing top cuisines by restaurant count
5. Geo Mapping — restaurant locations plotted on an interactive world map
6. City-wise Distribution — ranked list of cities by restaurant percentage share
